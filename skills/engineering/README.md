# Engineering

Skills for code work. Add new skills as their own folder containing a `SKILL.md`.

- **[abcdefg](./abcdefg/SKILL.md)** — End-to-end feature workflow (the entry point; auto-triggers, runs the phases in order): Analyze → Blueprint → Construct → Debug → Enhance → Finalize → Go.
  - Phase subskills (invoked by `abcdefg`, not standalone): [a-analyze](./abcdefg/a-analyze/SKILL.md) · [b-blueprint](./abcdefg/b-blueprint/SKILL.md) · [c-construct](./abcdefg/c-construct/SKILL.md) · [d-debug](./abcdefg/d-debug/SKILL.md) · [e-enhance](./abcdefg/e-enhance/SKILL.md) · [f-finalize](./abcdefg/f-finalize/SKILL.md) · [g-go](./abcdefg/g-go/SKILL.md)
- **[example-skill](./example-skill/SKILL.md)** — Template skill. Copy this folder to start a new one.
- **[grill-with-docs](./grill-with-docs/SKILL.md)** — grilling session that challenges a plan against the existing domain model, sharpens terminology, and captures decisions. *(Third-party, MIT — vendored from [`mattpocock/skills`](https://github.com/mattpocock/skills); see [`grill-with-docs/LICENSE`](./grill-with-docs/LICENSE).)*
