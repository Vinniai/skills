# Design

Skills for designing and building distinctive, production-grade interfaces.

- **[impeccable](./impeccable/SKILL.md)** — create distinctive, production-grade frontend interfaces that avoid generic AI aesthetics. Call with `craft` for the full shape-then-build flow, or `teach` to set up project design context. Ships eight `reference/` files (typography, color, spatial, motion, interaction, responsive, ux-writing, craft).
