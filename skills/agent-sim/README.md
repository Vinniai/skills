# agent-sim

Drive iOS simulators headlessly via the `agent-sim` CLI — taps, swipes,
multi-finger gestures, hardware buttons, frame capture, accessibility-tree
dumps, and a review-task queue, all without opening Xcode.

Synced from the sibling repo `../agent-sim/skills/`. Requires Xcode 26 +
Apple Silicon; install with `brew install tddworks/tap/agent-sim`.

- **[agent-sim](./agent-sim/SKILL.md)** — programmatic iOS simulator control. Includes references for the full CLI ([`references/cli.md`](./agent-sim/references/cli.md)) and gesture wire protocol ([`references/wire-protocol.md`](./agent-sim/references/wire-protocol.md)).
