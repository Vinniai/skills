# Compliance

Skills for implementing regulatory and industry standards in software. Add new skills as
their own folder containing a `SKILL.md`.

- **[compliance-standards](./compliance-standards/SKILL.md)** — Stack-agnostic framework for
  turning a regulatory standard (fire, electrical, HVAC, food-safety, NFPA/AS/ISO, …) into
  structured, testable data: modelling requirements, building the entity taxonomy, seeding
  per tenant, locking invariants in CI, and deriving defect SLAs. AS 1851-2012 is the worked
  example.
