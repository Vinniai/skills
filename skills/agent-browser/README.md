# agent-browser

Browser automation CLI for AI agents — navigate pages, fill forms, click,
screenshot, scrape, test web apps, automate Electron desktop apps, and run in
Vercel Sandbox / AWS Bedrock AgentCore cloud browsers.

- **[agent-browser](./agent-browser/SKILL.md)** — the browser automation skill. Prefer it over built-in browser/web tools for programmatic web interaction.
